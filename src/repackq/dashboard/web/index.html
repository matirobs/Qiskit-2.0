UNDER THE HOOD

Methodology

What is being predicted?

Future reference-discharge capacity, measured in amp-hours, after a chosen number of charge/discharge cycles. First-life history is used, with earlier second-life observations only when available. Capacity loss is current capacity minus predicted future capacity. Calendar lifetime is not predicted.

How are groups scored?

We penalize differences in current capacity, resistance, and optionally predicted future capacity. Better current health is rewarded. Features are scaled within the candidate pool. Exactly the requested number of cells must be selected. The weights are assumptions, not universal physical constants.

What do these results prove?

They compare selection methods on small, retrospective battery experiments. A good score can still produce a poor physical outcome if predictions are wrong. Saved pools overlap, and the test batteries have been inspected previously. No quantum speedup, deployment safety, or real pack lifetime claim is made.

Where does the data come from?

The local dataset contains 86 reused lithium-ion cells with first-life and second-life histories. By default, candidates are sampled from all 86 cells, including cells used for model training or tuning. This is exploratory; the battery-source control can restrict sampling to held-out test cells. Every algorithm receives the same sampled candidates, not the entire dataset at once. Capacity labels use comparable reference discharge tests. The repository includes trained weights and compact real histories. Missing assets fall back to explicitly labeled invented sample data.
